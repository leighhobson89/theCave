# Evidence system

Evidence awarded by visiting web content, and the magnifier lens over both
report text and photos.

| Spec | Covers |
| --- | --- |
| `evidence-awards-from-web-content.spec.js` | A standalone page awarding multiple evidences, each with its own reward toast |
| `evidence-magnifier.spec.js` | Magnifier over report text (including after scrolling) and over photos (alignment at centre and edge) |

Not yet covered here: carousel navigation (prev/next), empty carousel states,
custom evidence names, and missing-catalog-entry error paths — see
`docs/test-coverage-analysis.md`.
